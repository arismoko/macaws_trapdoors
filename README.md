# Macaw's Trapdoors for Sunrise

179 trapdoors in every wood plus glass and metal, with trapdoor prints.

A port of [Macaw's Trapdoors](https://github.com/sketchmacaw/Trapdoors) by Sketch Macaw and Peachy Macaw to [Sunrise](https://playsunrise.net) (Minecraft Java 26.3), as a content mod: the original's trapdoors, models, textures, recipes and strings, with no code.

## What it does

- The twelve prints say "Crafting Ingredient" in their tooltip and burn for 150 ticks, as the original's do.
- 176 wooden trapdoors: barn, barred, beach, cottage, four-panel, glass, mystic, paper, tropical, swamp, bamboo, blossom, classic, bark, ranch and barrel, in eleven woods.
- Three metal trapdoors that open only with redstone, like the iron trapdoor.
- The 12 trapdoor prints, recipes, drops and creative tab.

## Differences from the original

- None known.

## Building

With the Sunrise mod tool (`cargo sunrise-mod`, from the Sunrise SDK):

```sh
cargo sunrise-mod check
cargo sunrise-mod build    # target/sunrise-mod/mcwtrpdoors.smod
```

This version is made for the Sunrise Dev build `dev-2026-11-22-7cfdf81`.
